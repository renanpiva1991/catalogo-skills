# Catálogo de Skills

Página única, estática, que lista as skills instaladas no meu Claude Code —
o que cada uma faz, quando ela entra em cena e como acioná-la.

Publicada em **https://renanpiva1991.github.io/catalogo-skills/**

## Sobre este repositório

- `index.html` é **gerado**, não editado à mão. A fonte vive no meu vault
  privado; um script produz esta versão e remove os detalhes internos da
  empresa (fornecedor, número de negócio, endereço de sistema, parâmetros das
  fórmulas) antes de publicar.
- Arquivo autocontido: nenhuma fonte, script ou imagem externa. Abre offline.
- `robots.txt` e a meta `noindex` mantêm a página fora dos buscadores. Ela é
  para quem recebe o link, não para quem procura no Google.
